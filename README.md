# personal-portfolio
A modern, responsive personal portfolio web application showcasing my projects, technical skills, and experience. Built with a focus on performance, clean UI/UX, and scalability, it serves as a central hub to highlight my work in full-stack development, problem-solving, and software engineering.

## Contact form email

The `/api/contact` route uses Nodemailer. Configure these server-only environment variables before sending real messages:

```txt
SMTP_HOST=
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=
SMTP_PASS=
SMTP_FROM=
CONTACT_TO=
```
